# Báo cáo kiểm thử bản demo mock

Kiểm tra lại ngày 25/09/2026: `npm run build` và `npm run lint` đạt; `npm run test:cov -- --runInBand` đạt **35/35 test trong 9 suite**, coverage **92,54% statements/lines, 69,27% branches, 93,33% functions**. E2E nay tạo database `<DB_NAME>_jest` riêng, dùng BullMQ prefix riêng và ép `BITRIX_SYNC_ENABLED=false` trước khi tải ứng dụng; lượt chạy này không tạo thêm sync state trên database demo. Lệnh `mock:webhook` từ chối gửi khi `.env` đang bật đồng bộ CRM thật, trừ khi có cờ chủ động `--allow-live-bitrix-sync`.

Kiểm thử trên Windows ngày 24/09/2026, PostgreSQL 17 và Redis 7 qua Docker Compose. `npm run build` và `npm run lint` đạt. `npm run test:cov -- --runInBand` đạt **27/27 test trong 7 suite**; coverage kết hợp unit + E2E: **92.3% statements/lines, 68.83% branches, 95.41% functions**. JSON summary cục bộ ở `app/coverage/coverage-summary.json` (Git bỏ qua thư mục coverage). Tỷ lệ lines đạt mốc 80%; branches chưa đạt 80%.

Các ca E2E đã xác minh: health PostgreSQL/Redis; chữ ký HMAC hợp lệ/sai; event ID lặp và xung đột payload; chống trùng theo email/điện thoại; từ chối email/phone trỏ đến hai Lead khác nhau; campaign sale tạo đúng một Deal và chuyển thủ công lại không nhân đôi; CRUD Lead/Deal xóa mềm; analytics, CSV/JSON/XLSX; callback Deal won tạo một conversion mock; dead-letter cho email lỗi; payload theo ví dụ PDF; form/interaction timeline và quality score; cập nhật mapping/rule qua API và từ chối cấu hình không hợp lệ; Bearer session Redis/login/logout; báo cáo theo giờ idempotent; outbound retry 3 lần → failed → replay → receipt. Unit test mới bao phủ tiêu chí gán sales, xác suất Deal, phân giờ/ngưỡng cảnh báo và custom field mapping.

Docker image multi-stage đã build lại sau thay đổi CRUD; `app`, `postgres`, `redis` lên trạng thái healthy. `/health` trả PostgreSQL/Redis `ok`; `/openapi.json` trả 200; danh sách Lead trả 7 bản ghi demo hiện có; xuất XLSX trả HTTP 200 và 7092 byte. Import lịch sử mock 2 dòng trả `accepted:2`, chạy lại trả `duplicate:2`; `historical-demo-1` được worker xử lý thành công. Migration mới 07–10 áp dụng thành công trên dữ liệu hiện có; báo cáo theo giờ đọc được và các outbound events có trạng thái `delivered` trong mock sink.

Các ca **chưa** có: API thật TikTok/Bitrix24, timeout/rate limit của CRM thật, conversion outbound thật và phân quyền production. Kết quả này chứng minh bản mock end-to-end, không chứng minh tích hợp tài khoản thật. `npm audit --omit=dev` báo 2 advisory moderate do ExcelJS kéo `uuid` cũ; nên thay/thẩm định dependency trước production. Không tự động chạy `npm audit fix --force` vì có thể đổi API/breaking.
